Nodly — a one-sentence pitch for a startup so strange it sounds like a joke, until the money logic lands: trained actors attend your Zoom meetings in your place, nodding wisely and agreeing at exactly the right moment, so remote workers can skip every call and still get promoted, billed per meeting.

## Run it

```sh
node main.ts
```

This writes the pitch to `/output/entry.txt` (override the directory with `OUTPUT_DIR`).
